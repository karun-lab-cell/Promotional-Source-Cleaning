# 📊 Promotional Source Data Cleaner

An interactive Streamlit application designed to clean, standardize, validate, and export promotional source data from CSV or Excel files.

This tool automates repetitive data-cleaning tasks and generates a formatted Excel output ready for reporting and operational use.

---

## 🚀 Features

- Upload CSV or XLSX files
- Preview raw uploaded data
- Clean and standardize publisher IDs
- Create `Pub_Id_replaced`
- Standardize Promotional Source values
- Normalize inconsistent naming variations
- Apply promotional source mappings
- Generate promotional source distribution summary
- Preview cleaned data
- Export formatted Excel file
- Download cleaned data directly from the dashboard

---

## 🛠️ Technologies Used

- Python
- Pandas
- OpenPyXL
- Streamlit
